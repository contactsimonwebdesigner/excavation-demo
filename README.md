# ZEMKOP. — růžně? NE: žlutá / oranžová verze s reálnými fotografiemi

Statický DEMO web pro zemní práce. Zachována struktura, texty i interaktivní funkce.

## Fotografie

Původní generované fotografie byly **zcela odstraněny**. Ve webu se nyní zobrazují **skutečné fotografie z Pexels načítané přes HTTPS**. Pro jejich zobrazení je potřebné internetové připojení. Pokud chcete fotografie hostovat sami, použijte samostatný archiv `ZEMKOP_REAL_FOTO.zip`: jeho obrázky rozbalte do `assets/images/` a v `index.html` změňte URL na odpovídající relativní cesty `assets/images/nazev.webp` (včetně konstanty `REAL_PHOTOS`).

## Spuštění

Otevřete `index.html` v prohlížeči s internetem nebo umístěte stránku na GitHub Pages. Není potřeba instalace.
